# API тесты для сервиса доставки самокатов

Проект содержит автотесты для проверки API сервиса доставки самокатов.
Тесты написаны с использованием фреймворка pytest и библиотеки requests.
Для формирования отчётов используется Allure.


## Структура проекта:

* endpoints.py — эндпоинты API
* urls.py — базовый URL
* helpers.py — вспомогательные функции
* tests/ — директория с тестами:

  * test\_create\_courier.py — тесты создания курьера
  * test\_login\_courier.py — тесты авторизации курьера
  * test\_create\_order.py — тесты создания заказа
  * test\_order\_list.py — тесты получения списка заказов
* conftest.py — общий файл для фикстур и конфигурации
* requirements.txt — список зависимостей
* README.md — описание проекта


## Установка зависимостей:
Создайте виртуальное окружение (по желанию) и установите зависимости с помощью команды:
``` pip install -r requirements.txt ```


## Запуск тестов:
Для запуска всех тестов выполните команду:
``` pytest ```

Для более подробного вывода:
``` pytest -v ```


## Генерация отчёта Allure:

Запуск тестов с сохранением результатов для Allure:
``` pytest --alluredir=allure_results ```

Запуск allure-отчета:
``` allure serve allure_results```


## Что покрывают тесты:

* Создание курьера: успешное создание, ошибки при дубликатах и при отсутствии обязательных полей
* Логин курьера: успешная авторизация, ошибки при неправильных данных и при отсутствии полей
* Создание заказа: проверка создания с разными значениями цвета (BLACK, GREY, оба, ни одного)
* Получение заказов: получение списка всех заказов
